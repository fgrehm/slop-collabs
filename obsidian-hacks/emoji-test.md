# Obsidian Hacks emoji test

Use these task markers to test the plugin in Reading View and Live Preview. After moving this note into the vault, rebuild and reinstall the plugin if you change `src/task-icons.json`.

## Task icon mappings

- [/] `/` -> Scheduled / incomplete: ⏳
- [w] `w` -> In progress: 🚧
- [x] `x` -> Complete: ✅
- [<] `<` -> Scheduled: 📅
- [?] `?` -> Question: ❓
- [!] `!` -> Important: ⚠️
- [-] `-` -> Canceled: ➖
- [*] `*` -> Star: ⭐
- [f] `f` -> Fire: 🔥
- [I] `I` -> Idea: 💡
- [b] `b` -> Bookmark: 🔖
- [r] `r` -> Reminder: 🎗️

## Click test

Click a custom icon and check whether it changes to an unchecked task:

- [/] Click the hourglass
- [w] Click the construction icon
- [x] Click the completed checkmark

## Plain task controls

- [ ] Unchecked task
- [x] Checked task
